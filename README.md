### Cloud Migration Assessment
If this local KillerCoda Linux virtual environment were to be migrated to the major public cloud platforms, it could be hosted natively using the following equivalent compute services:
* **Amazon Web Services (AWS):** Amazon EC2 (Elastic Compute Cloud) running an `t3.medium` or `t2.medium` instance type.
* **Microsoft Azure:** Azure Virtual Machines utilizing a `Standard_B2s` or `Standard_D2s_v5` size tier.
* **Google Cloud Platform (GCP):** Google Compute Engine (GCE) configured on an `e2-medium` general-purpose machine type.
