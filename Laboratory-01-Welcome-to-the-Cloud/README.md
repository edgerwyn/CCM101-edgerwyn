# Mission 1: Welcome to the Cloud

## Mission Overview
Onboarding challenge as a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies.

## Objectives
* Deploy environments via KillerCoda
* Manage users and file system hierarchies
* Link local workspaces securely to GitHub repositories

## Activities Performed
1. Provisioned an Ubuntu server instance
2. Created a dedicated user profile with administrative access
3. Generated file trees and recorded system baselines
4. Tracked the workspace setup inside GitHub

## Linux Commands Used
* `useradd`, `passwd`, `usermod`, `su`
* `mkdir`, `cp`, `ls`
* `cat`, `nano`
* `git init`, `git add`, `git commit`

## Skills Learned
* Secure environment isolation
* System baseline auditing
* Git version control integration
