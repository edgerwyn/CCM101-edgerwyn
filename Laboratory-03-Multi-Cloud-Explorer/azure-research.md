# Microsoft Azure Cloud Platform Research Report

## Brief Overview
Microsoft Azure is a public cloud computing platform developed by Microsoft. Launched in 2010, it is heavily tailored for hybrid cloud integration and enterprise-grade environments.

## Global Infrastructure
* **Regions:** 60+ Active Deployment Regions
* **Availability Zones:** 120+ Geographically Isolated Zones
* **Edge Locations:** 180+ Global Network Points of Presence

## Cloud Management Console
The Azure Portal is a unified console that provides a customizable, single pane of glass for building, managing, and monitoring everything from simple web apps to complex cloud deployments.

## Four (4) Core Services
1. **Compute:** Azure Virtual Machines - Scalable on-demand infrastructure instances.
2. **Storage:** Azure Blob Storage - Unstructured massively scalable object storage.
3. **Networking:** Azure Virtual Network (VNet) - Private secure isolated networking profiles.
4. **Identity:** Microsoft Entra ID - Cloud-based identity and access management suite.

## Three (3) Advantages
* **Microsoft Ecosystem Integration:** Seamless native integration with Windows Server, SQL Server, and Microsoft 365.
* **Hybrid Capabilities:** Best-in-class hybrid options via Azure Arc and Azure Stack frameworks.
* **Enterprise Agreements:** Highly beneficial cost optimizations for long-term Microsoft enterprise agreement holders.

## Typical Enterprise Use Cases
* Enterprise hybrid-cloud hosting architectures.
* Migrating and scaling legacy Windows Server workloads.
